# Первоначальный аудит TraceMemo International

Дата: **21 октября 2026 года** (Europe/Moscow). Базовый commit форка и проверенного upstream `main`: `c366dd11871d75d5f511e843605b689731759622`, приложение `2.5.1`.

## Основные результаты

| Приоритет | Подтверждённый факт | Следствие |
| --- | --- | --- |
| P0 — до распространения сборок | В проверенном дереве нет общей лицензии; GitHub API сообщает `license: null` | Право публиковать производные сборки не установлено; нельзя самостоятельно объявить весь проект MIT/GPL |
| P0 — до загрузки native-компонентов с данными | В `resources/libwcdb_api.dylib` есть строки `https://api.weflow.top/api/report`, `/api/token` и символ `_wcdb_cloud_report` | Требуются исходники/статический разбор компонента; **это ещё не доказательство выполненного запроса или утечки** |
| P0 — до International-сборки | Updater, publish target и `appId` остались от upstream | Возможны получение обновлений оригинала и смешение идентичности приложений |
| P1 | Токены iLink и контекстные токены записываются в JSON, не через `safeStorage` | Локальная компрометация/копия профиля раскрывает эти секреты |
| P1 | Нет общей проверки доверенного отправителя IPC; renderer имеет широкий мост | Компрометация renderer получает доступ к чувствительным операциям |
| P1 | Согласие на отправку AI-данных неодинаково защищено в разных входных путях | Нужна единая политика в main, включая Query Agent, отчёты, изображения и Agent Hub |
| P1 | `pnpm audit` вернул 129 advisory-записей | Нужна отдельная проверка достижимости и обновление зависимостей, без автоматического `audit fix` |

P0/P1 обозначают порядок работ, а не CVSS. Подробные условия и ограничения выводов приведены в основном отчёте.

## Доказательства и ограничения

Проинвентаризированы **878 tracked-файлов**, в том числе **19 PE/Mach-O-компонентов**. [SHA-256 и архитектуры](evidence/native-binaries.csv), [кандидаты сетевых литералов](evidence/network-literals.csv), [advisories с цепочками зависимостей](evidence/dependency-advisories.csv) и [сводка](evidence/inventory-summary.json) привязаны к базовому commit. Отдельно записаны [hashes 9 просмотренных dependency-файлов](evidence/inspected-dependency-files.csv), включая updater. CSV сетевых литералов содержит также документацию, тесты, XML namespace и строки бинарников; он не является журналом соединений.

До уточнения пользователем режима «только статический аудит» были выполнены существующие целевые тесты: 50 unit, 96 integration и 5 тестов share-card worker — все прошли. Они проверяют синтетические данные и mocks, не доказывают отсутствие уязвимостей. Установка и более широкие проверки из предшествующего onboarding не считаются результатами статического аудита этого PR. После уточнения скрипты проекта и native-компоненты не запускались; оставшийся dev-процесс остановлен.

В ходе исследования выполнялись Git/GitHub-запросы метаданных и `pnpm audit` к npm registry (имена и версии пакетов). Запросы к AI, Tencent, WeFlow, share-card сервисам и загрузка моделей не выполнялись. Переписка и секреты наружу не отправлялись. API GitHub использован только для чтения upstream и работы с ветками/PR **форка**.

Следующий этап: сначала юридические разрешения и проверяемое происхождение native-компонентов, затем отдельные PR по границам безопасности и изоляции International-сборки. После этого — инфраструктура i18n, без изменения протоколов WeChat и бизнес-логики.
